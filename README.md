# Blackjack in PowerShell

Ein simples Blackjack-Spiel fuer das Terminal mit Coins und Einsaetzen.

## Starten

```powershell
.\blackjack.ps1
```

## Spielen

- `z` zieht eine weitere Karte.
- `h` haelt deine Hand.
- Der Dealer zieht bis mindestens 17 Punkte.
- Du startest mit `500` Coins und setzt vor jeder Runde einen Einsatz.
